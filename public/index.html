How this works

No server ever holds your .env. One machine encrypts it and broadcasts on the local network; the other, given the same room code and passphrase, finds it and decrypts it directly. Nothing but these two machines ever sees the plaintext.

Honest limit: this finds a peer only on the same local network (same LAN / Wi-Fi broadcast domain) — it cannot cross the public internet or a NAT boundary. That's the same real tradeoff that removes the central server, not an oversight. A weak passphrase is still a weak passphrase — this doesn't strengthen it.
